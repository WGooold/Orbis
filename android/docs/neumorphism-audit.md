# Android 新拟物覆盖审计

范围：`MainActivity.kt`、`RemoteUi.kt`、`Neumorph.kt`、`AgentBrand.kt`、`MarkdownText.kt`、`HistoryTreePage.kt`、`QrPairing.kt`、主题与系统入口。对应 0.1.42。

## 已采用的区域

| 页面 / 场景 | 新拟物处理 |
| --- | --- |
| 配对 | 通用电脑图标的凹槽底座；扫码、连接、相机授权与取消按钮凸起；地址 / 配对码输入凹陷。 |
| 在线会话主页 | 会话卡片凸起，agent 标志凹陷；菜单、下载、编辑、侧栏按钮均有按压反馈；更多菜单面板与菜单项使用同一套材质。 |
| 侧栏 | 抽屉内不再铺整块凸起底板，内容与页面共用同一块地面；主机选择与主机菜单贴着抽屉底部、按当前主机展示，目录折叠行、会话行、新建 / 刷新 / 历史按钮、展开全部按钮均覆盖。展开的目录为凹陷，未展开目录为凸起。 |
| 新建会话 | 弹层外缘与拖动柄；Pi / Codex 选择、上一级、目录行、新建按钮。选中的 agent 凹陷，图标和名称始终可辨识。 |
| 在线聊天 | 会话顶部信息块两行（标识与标题 / 运行状态与模型）保持平面文字；输入框上方统一为会话信息区，左侧两行目录与分支，右侧轻量权限入口，窄屏 / 大字体时上下排列。附件按钮、输入框、发送 / 停止按钮保持同一行。Follow-up / Steer、返回、下载、跳到最新、命令和选项均覆盖。 |
| 历史与分支 | 搜索框凹陷，筛选菜单、回到当前位置、返回、分支折叠按钮凸起；节点面凸起、当前位置与预览中的节点凹陷；分支摘要行、细节折叠行、预览面板与预览动作按钮覆盖。分支缩进连接线不叠阴影。 |
| 聊天与只读历史 | 用户消息为靠右凹陷面；助手每个轮次为一个浅凸起面；错误回复、提示、思考 / 工具折叠栏、工具输出和排队消息为凹陷面。 |
| Markdown | 代码框及复制按钮、引用框、表格外框、图片外框、文件下载按钮。 |
| 附件与下载 | 上传附件条凹陷，移除按钮凸起；下载任务卡片凸起，选中时凹陷，长按多选保留；下载 / 取消 / 重试 / 删除按钮和勾选框覆盖。 |
| 设置与连接状态 | 内容卡片、连接状态胶囊、优先级调整按钮、诊断入口均覆盖。 |
| 弹窗 | 错误、会话别名、原始事件、扫码和交互确认使用统一凸起面板；输入、选项、参数摘要、提交 / 拒绝等操作覆盖。保留原有取消规则与交互截止时间。 |
| 相机预览 | 预览外框凹陷，图像本体保持原貌。 |

选中、禁用和按压不改变控件尺寸。普通操作最小触控区域 48dp，输入框最小 56dp。新拟物只负责表面材质，不替换滚动、文字选择、焦点、键盘和模态交互契约。

## 仍保持平面的部分及原因

这里列的是最终界面中的例外，不把已使用新拟物组件内部的图标或文字误列为“遗漏按钮”。

| 位置 / 元素 | 保持平面的原因 |
| --- | --- |
| 所有页面的连续背景、`Scaffold`、顶栏背景、抽屉地面、输入区地面、列表的空白与内边距 | 它们是承载凸起与凹陷的同一块底板。再给整屏和每个留白区叠影会割裂材质，并挤占滚动/键盘空间；独立控件和内容面已有层次。 |
| 所有标题、正文、说明、路径、时间与耗时、版本号、空状态提示、错误说明文字、队列条目文字 | 阴影不画到字形上，保持小字号和长文清晰。文字所在的独立卡片/弹窗已经使用新拟物，不为每行内容再建立一个表面。 |
| Pi / Codex 标志和普通图标的图形本体 | 保留矢量轮廓、官方形状/颜色及小尺寸识别度。需要底座的标志和按钮已有新拟物外壳；标题/正文中的图标随文字直接显示。 |
| 连接 / 运行 / 下载状态点、状态胶囊内部的文字；目录“有历史”和下载数角标 | 点和角标需要清晰、紧凑地编码状态或数量。角标本身通常只有约 16–20dp，柔影会侵入相邻内容；外层连接胶囊、任务卡片或操作按钮已塑形。 |
| 所有圆形 / 线性加载指示器、下载进度、输入区顶部上下文容量细线 | 这是随时间变化的数据编码。保留准确的长度、边界与颜色；给轨迹叠影会模糊百分比，特别是 2dp 容量线。周围的任务/输入区域已有新拟物表面。 |
| 输入框焦点 / 错误描边、错误颜色与选中提示文字 | 清晰的边界和颜色是键盘焦点与错误状态的辅助提示，不能只靠微妙明暗表达。输入框的底面仍是凹陷。 |
| 输入框上方的当前会话权限入口 | 与目录 / 分支共同表达当前会话状态，不再使用通栏凸起按钮。图标、短标签和箭头提示可点击，保留至少 48dp 触控高度和按压反馈；异常用错误色与明确文字提示。完整策略与修改操作仍在原权限面板中。 |
| Markdown 行内链接、粗体/斜体/行内代码、段落、标题、列表编号、项目符号 | 行内元素必须保留排版基线、换行、复制和链接点击行为。独立下载路径另提供新拟物按钮，正文内的链接保持正常文字链接。 |
| Markdown 任务列表的勾选标记 | 它描述消息内容，不能在手机上直接切换。沿用清晰的只读勾选图形，避免冒充可编辑勾选按钮；真正的交互多选框已使用新拟物。 |
| Markdown 表格各单元格、网格线与表头底色 | 表格整体已有凹陷外框。每格继续塑形会破坏连续网格、对齐和横向比较，长单元格还会形成大量重复阴影。 |
| Markdown 引用的左侧标识线、水平分隔线；页面分隔线 | 线条只负责表示引用或分段。引用块外框已经凹陷；线条叠影会造成多余的双线。 |
| 图片像素、扫码相机画面 | 阴影不覆盖图像或改变二维码识别区域；外框使用新拟物，原始图像保持色彩与细节。 |
| 历史树的分支缩进连接线、预览面板里的对话内容 | 连接线表达分支的连通关系，必须连续且不干扰节点层级，节点本身、分支摘要行与折叠动作已经使用新拟物。预览复用聊天页的用户/助手消息形态，材质规则与聊天页一致，不再单独塑形。 |
| 模态遮罩、系统滚动/文本选择交互 | 遮罩表达“背景暂不可操作”；选择手柄与文字操作保持 Android 一致的交互。内容弹层本体使用新拟物。 |
| Android 键盘、系统文件选择器、相机/通知权限提示、系统 Toast、状态栏与导航手势条、桌面启动器 | 由系统或其他应用绘制，Orbis 不控制其材质。应用自身的输入框、附件入口、权限解释面板、扫码界面和按钮均已覆盖。启动图标仍由桌面按系统规则呈现。 |

## 验证

- 以源码全量查找 `clickable` / `combinedClickable` / `selectable` / `toggleable`、Material 按钮/卡片/弹窗/菜单、`background`、进度与徽标等入口，再逐项核对调用点。
- `RemoteUi.kt` 中保留的 Material 输入、菜单和模态底层负责焦点、语义与定位；其外观由新拟物封装接管，不算视觉遗漏。
- Markdown 滚动/链接及本地存储的 5 项设备测试已通过。配对页实机核对暴露的 Codex 矢量问题已修正；用户要求后续自行测试，因此最终图标、聊天、抽屉和弹窗的视觉验收留待用户完成。
- 最终版本运行 Android 单元测试、lint 和 APK 构建；不再自动运行真机测试。首次设备测试触发 AGP 默认卸载，导致手机端配对和本地缓存丢失；现已在 `gradle.properties` 禁用测试后卸载，详见 Android README。
