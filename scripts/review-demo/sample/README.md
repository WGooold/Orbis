# Orbis App Review Workspace

This project contains demonstration files only. The connected Pi agent uses a real
DeepSeek Flash model through the normal DeepSeek API integration.

Try asking the agent to:

1. Read this README and explain `hello.js`.
2. Change the greeting in `hello.js`, run it with Node, and show the changes.
3. Create a short `NOTES.md` describing the change.

You can inspect streamed responses, tool calls, session history and files in Orbis.
Changes and conversations are shared among the Apple review devices connected to
this demo. Use demonstration data.

This environment has Pi only. Codex Desktop, Claude Code and DeepSeek desktop
integrations require their respective software on the user's own computer.
