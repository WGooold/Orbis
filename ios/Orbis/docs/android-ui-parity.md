## 验证方式

- `scripts/check-ios.sh`：同源 Swift Testing、加密协议 / Relay 根路径和前缀互通、Swift 解析、工程 / plist / scheme 校验及模拟器构建。
- `OrbisUITests`：通过显式 Debug 启动参数加载内存夹具，验证搜索、新建入口、草稿返回和分支预览；捕获浅色 / 深色页面截图。
- UI 夹具不读取 Keychain，不连接生产 Host，不修改真实配对或真实会话。Release 不包含夹具。
- 本次只操作专用模拟器；未安装用户真机，未重启 Host，未清除现有模拟器或真机的数据。
- 文件传输另有分片格式、Host 归属、偏移 / 重复分片、断点续传、来源变化、上传范围读取和最终校验测试。核心测试成功不等于真实设备 / 网络验收完成。

Agent 图标直接复用 Android 素材，来源与许可见 `AGENT-ICON-NOTICES.txt`。


工具详情采用固定内容版本和 UTF-8 字节游标，单页请求 32 KiB、查看器缓存最多 2 MiB；关闭、切换会话、后台或断线停止读取。工具清单取得完整固定快照前保留原清单；聊天快照的工具依赖确认前不发送完整 applied 回执。历史分页使用独立 range，不改变 live/source 位置；旧 preview 不得回退已应用的新来源版本。


第一轮本机验证结果：43 项 Swift 核心测试通过、5 项专用 iPhone 17 模拟器 UI 测试通过，模拟器 Debug 构建成功。UI 验证包含 8 个页面 / 场景的浅色与深色截图、会话搜索、新建入口、草稿返回、历史预览 / 继续和工具详情多页读取 / 关闭。

第二轮继续对齐设置、供应商、状态与目录筛选。Host 状态按当前安全连接的请求 ID、模型代次和分域版本接收；缺席、未知、空清单和截断分开显示。供应商清单更新不代表操作回执已完成，只有匹配 Host / kind / requestId 的回执才能结束处理中。诊断记录按 Host 游标朝更新方向读取，不能将第一页误称为最新记录。会话 provider 归属使用原生 `modelProvider`，与 Host 供应商 profile ID 分开。54 项 Swift 核心测试通过（含 Relay 根路径与 `/relay/` 前缀互通），7 项专用模拟器 UI 测试通过，无运行时警告，模拟器 Debug 构建成功。截图覆盖 9 个页面 / 场景的浅色与深色，新增操作验收包含优先级上下移动、供应商确认 / 取消 / 成功回执、Pi 默认移除提醒、诊断翻页、provider 筛选和不匹配会话转到设置。

未进行真实 Host 文件 / 审批 / 分支 / 供应商切换端到端验收。

2026-10-29 核心能力接入后的验证：17 项展示逻辑测试、5 项多 Host 隔离测试通过；后者覆盖同 runtime / session ID 的历史、状态及消息路由，选中电脑不重连，偏好合并，取消配对和 LAN 路由持久化。专用 Orbis Core Parity 模拟器验证队列撤回、通知关闭与核对、会话状态面板、工具输出导出、交互表单输入与多请求草稿恢复、工具参数和结果关联、截断内容取全文、Codex 桌面版接入原因；9 个页面的浅色 / 深色截图及新增入口截图已检查。截图复查发现的交互表单零高度和导出清空当前阅读内容问题均已修复，工具读取 / 导出的 11 项测试通过。上述 UI 流程使用隔离夹具，未替代真实 Host 或真机验收。

第三轮（2026-10-28）修正四处体验问题：

- 会话目录按最近使用排序：目录以其中最新会话的修改时间倒序，目录内会话同样按时间倒序（与 Android `cachedHistoryTree` 一致）。一次只展开一个目录，默认展开当前会话所在目录、否则最近的目录；展开后先列最近 5 条，其余由「再显示 N 个会话」展开。移除「展开全部」。
- 会话目录抽屉可拖动：主页左缘向右拖出、在抽屉或遮罩上向左推回，位置随手指移动，松手按位置与速度吸附；竖向滚动目录不会带动抽屉。
- Agent 类别：Host 的 `RuntimeMetadata` 不带 `agentKind`，此前缺省显示为 Pi。现在先用会话目录中同一会话的 `agentKind`，再按 Host 的 runtimeId 约定识别 `codex[:thread]`、`codex-desktop[:thread]`、`dsh:<id>`；仅用于显示，不改动协议校验。Android 通过 Agent 作用域的 identity 领域取得该字段，iOS 尚未订阅该领域。
- 新拟物覆盖：系统 `Menu`、`alert`、`confirmationDialog`、`contextMenu`、`Toggle` 与裸文字按钮全部换成同一材质的菜单面板（凸起面板、每项凸起、选中凹陷）、对话框、开关、勾选框和小号文字按钮；弹层使用基础底色和凹槽拖动柄。菜单和对话框绘制在抽屉之上的统一图层。仍保留系统的：文件选择器、分享面板、相机权限、键盘与文本选择、下拉刷新指示器。
