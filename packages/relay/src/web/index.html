GOOD TO KNOW

连接前，了解一点。

需要一直开着电脑吗？

需要。Host 和 Agent 在电脑上运行，手机连接这台电脑继续工作。关闭电脑或暂停 Host 后，远程会话暂不可用。

为什么需要 QQ 邮箱？

是否要求 QQ 邮箱验证码由 Relay 管理员设置决定，页面会显示当前注册方式。

Relay 能看到我的聊天和文件吗？

手机与 Host 间的会话内容经过端到端加密。Relay 能看到路由、连接状态与注册信息，但无法解密聊天和文件载荷。

能控制电脑上的所有程序吗？

Orbis 面向受支持的 Agent 会话，提供消息、交互和文件操作。它不提供远程桌面或任意命令行执行入口。

目前可以查看源码吗？

Orbis 已采用 MIT 许可证开源。你可以查看源码、自行部署、修改和参与贡献：GitHub · WGooold/Orbis。第三方依赖保留各自许可证。
