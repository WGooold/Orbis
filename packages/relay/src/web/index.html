GOOD TO KNOW

开始之前，
你可能想知道。

Orbis 免费吗？

Orbis 和官方公共连接服务免费使用，无需自己购买服务器。你使用的 AI 工具或模型服务如有费用，仍按其各自的规则计费。

需要一直开着电脑吗？

需要。AI 工作仍在你的电脑上进行，使用时请保持电脑开机、联网，并让 Orbis 和相应的 AI 工具运行。

为什么需要 QQ 邮箱？

QQ 邮箱用于接收激活验证码，只需按客户端提示操作，不需要提供 QQ 密码。

目前支持哪些 AI 工具？

目前支持 Pi 与 Codex。Codex 桌面版、DeepSeek Harness、Claude Code 等已列入后续接入计划，尚未上线。

iPhone 可以使用吗？

目前提供 Windows 电脑端和 Android 手机端，暂未提供 iPhone 版本。

遇到问题或有新想法，怎么反馈？

我们会持续维护、修复问题并改善体验。欢迎到 反馈页面告诉我们遇到的情况或期待的功能。
