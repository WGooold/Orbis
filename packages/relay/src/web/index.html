GOOD TO KNOW

开始之前，
你可能想知道。

Orbis 和官方远控有什么不同？

官方远控通常绑定对应产品的账号、远控服务和网络链路。Orbis 把控制面放在你的电脑与手机之间：使用电脑上已配置的兼容 API 供应商，不要求官方远控账号，也不依赖对应产品的官方远控云。模型 API 本身仍需要有效凭据，并按服务商规则联网和计费。

自己的 API 密钥会上传到手机或 Relay 吗？

不会。供应商地址、模型与凭据保留在电脑端 Host；手机只选择电脑上已保存的供应商，Relay 只转发端到端加密后的业务内容和必要路由信息。

Orbis 免费吗？

Orbis 和官方公共连接服务免费使用，无需自己购买服务器。你使用的 AI 工具或模型服务如有费用，仍按其各自的规则计费。

需要一直开着电脑吗？

需要。AI 工作仍在你的电脑上进行，使用时请保持电脑开机、联网，并让 Orbis 和相应的 AI 工具运行。

为什么需要 QQ 邮箱？

QQ 邮箱用于接收激活验证码，只需按客户端提示操作，不需要提供 QQ 密码。

目前支持哪些 AI 工具？

目前支持 Pi、Codex 和 DeepSeek Harness。电脑端提供 Agent 安装更新与供应商配置，手机端可切换已保存的供应商；更多 Agent 会继续接入。

iPhone 可以使用吗？

目前提供电脑端和 Android 手机端，暂未提供 iPhone 版本。
