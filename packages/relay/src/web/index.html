WHY ORBIS

远控不绑定官方账号，
Agent 也不止一种。

用自己的 API，在一个手机界面里接续多个 Agent。

⌘01

使用自己的 API

Codex 使用电脑上已配置的兼容 API 供应商与有效凭据。Orbis 不要求 Codex 官方远控账号，也不依赖官方远控云；模型 API 的网络与费用仍按服务商规则。

⇄02

多个 Agent，一处控制

在同一个 Android 客户端管理 Pi、Codex 与 DeepSeek Harness 会话。按你的工作流选择工具，不必为每个 Agent 切换一套远控产品。

✓03

Relay 看不到会话内容

消息、历史与文件在设备间端到端加密。Relay 负责连接和转发密文，只能看到建立连接所需的路由元数据。

GOOD TO KNOW

开始之前，
你可能想知道。

Orbis 和官方远控有什么不同？

官方远控通常绑定对应产品的账号、远控服务和网络链路。Orbis 把控制面放在你的电脑与手机之间：Codex 使用电脑上已配置的兼容 API 供应商，不要求官方远控账号，也不依赖 Codex 官方远控云。模型 API 本身仍需要有效凭据，并按服务商规则联网和计费。

自己的 API 密钥会上传到手机或 Relay 吗？

不会。供应商地址、模型与凭据保留在电脑端 Host；手机只选择电脑上已保存的供应商，Relay 只转发端到端加密后的业务内容和必要路由信息。

Orbis 免费吗？

Orbis 和官方公共连接服务免费使用，无需自己购买服务器。你使用的 AI 工具或模型服务如有费用，仍按其各自的规则计费。

需要一直开着电脑吗？

需要。AI 工作仍在你的电脑上进行，使用时请保持电脑开机、联网，并让 Orbis 和相应的 AI 工具运行。

为什么需要 QQ 邮箱？

QQ 邮箱用于接收激活验证码，只需按客户端提示操作，不需要提供 QQ 密码。

目前支持哪些 AI 工具？

目前支持 Pi、Codex 和 DeepSeek Harness。电脑端提供 Agent 安装更新与供应商配置，手机端可切换已保存的供应商。Codex 桌面版与 Claude Code 仍在后续接入计划中；它们接入后，同样会围绕各自的本地配置与 API 使用场景设计。

iPhone 可以使用吗？

目前提供 Windows 电脑端和 Android 手机端，暂未提供 iPhone 版本。
