# Security reports

Report vulnerabilities privately using GitHub's **Report a vulnerability** option in this repository's Security tab. Do not post active credentials, pairing material, personal data or exploit details in public issues.

Include affected versions, reproduction steps and impact. The project is currently a preview; there is no guaranteed response time. Deploy maintained builds and retain a recoverable copy of server state before upgrades.

The Relay sees routing metadata and registration records but is not intended to decrypt Host/device payloads. Revoking a device's Relay credential does not revoke its Host-side trust; remove a paired device in the Host to revoke every transport path.
