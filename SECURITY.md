# Security reports

Report vulnerabilities privately using GitHub's **Report a vulnerability** option in this repository's Security tab.

Include affected versions, reproduction steps and impact. The project is currently a preview; there is no guaranteed response time. Deploy maintained builds and retain a recoverable copy of server state before upgrades.

The Relay manages routing metadata, registration records and Relay credentials. Host/device payloads use end-to-end encryption. Remove a paired device in the Host to revoke trust across every transport path.
