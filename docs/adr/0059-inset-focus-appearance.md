# ADR-0059：双端“雾蓝”外观

日期：2026-11-02

Status: implemented，设备与人工回归验证中

## 决策

用户提供的参考图只作为视觉参考，不采用图中的产品文案、数据和操作。iOS 与 Android 新增可选的“雾蓝”外观；设置页“外观”分区提供“经典”和“雾蓝”两个同尺寸单选控件，当前选择呈内凹、蓝色文字和对勾。默认保持经典，选择立即作用于当前页面并在本机持久化；切换不会重建导航、会话、消息或输入状态，也不需要 Host 同步。两端各自保存选择，不跨设备同步。

2026-11-02 命名修订：设置页显示名统一为“雾蓝”。iOS 的 `orbis.visualStyle` 与 Android 的 `visualStyle` 仍保存 `insetFocus`，测试标识也保持原值，已保存的选择无需迁移。

参考图的识别元素为偏中性的浅灰蓝连续底板、上白下灰的柔影、较明显的内凹输入/选项、灰蓝正文和柔和蓝色强调。实现仍沿用 S01–S13 的四层、单材质外框、圆角、字号、可访问性和聚焦规则；不复制截图中与 Orbis 无关的搜索、统计卡、进度和表格。明亮外观的四层色是 `#E4E7EF / #EEF0F5 / #F3F5F9 / #FAFBFD`，文字 `#4A5368`、次要文字 `#798396`、强调色 `#5F8FE5`，暗影 `#A9B2C3`；系统深色下使用对应的深蓝灰四层 `#222A39 / #293244 / #303B4F / #37435A` 与 `#8DB4FF` 强调色。经典主题色值与阴影保持原值。内凹态阴影强度只在该外观增加，不改按压、焦点、菜单或页面转场的时间参数。

供应商身份色、语义成功/警告/错误色、消息来源与 Host 事实不随主题改写。外观选择和系统明暗是两个独立维度；两端设置和首页/聊天/目录/下载等共用材质均随选择变化。失效或未知持久化值回退经典。

## 回归

影响 S01–S04、S12、S19、S22，新增 S25。选择属于设置页一般触点，复用 ADR-0058 ActionGlyph / 共用按钮按压，不引入新动效家族。自动用例：iOS `testInsetFocusAppearanceSwitchPersistsAcrossLaunches`，Android `SettingsEntryInstrumentedTest#insetFocusAppearanceSwitchUpdatesSelectionWithoutLeavingSettings`，以及既有两端全页面明暗、设置、材质和输入用例。人工按 UI 回归方案 R44 在两端经典/雾蓝 × 系统明/暗、A3 大字窄屏、A4 减少动画下检查设置、首页、目录、聊天输入焦点、下载和返回；前后对照截图审阅底板/阴影方向/文字对比/触控尺寸，并验证切换中草稿、滚动、导航与连接状态不变。设备门禁未完成前不得标为验收通过。

命名修订验证：iOS 设置页定向 UI 用例包含“雾蓝”可访问名称断言，1 / 1 通过；Android 设置页用例补入显示文字断言，构建通过，但两次设备安装均因 ADB 断连中止，未执行该断言。完整 L1–L4 和人工门禁仍待完成；记录见 `.artifacts/ui-regression/20261102-fog-blue-rename/summary.md`。
