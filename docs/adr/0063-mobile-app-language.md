# ADR-0063：移动端中英文与系统语言

日期：2026-11-04

Status: accepted（用户授权整个 App；实施与设备验收分别记录）

## 规则

- S27 / r45：iOS 和 Android 的首页、目录、聊天界面、设置、配对、下载、文件审阅、交互面板、弹窗及辅助功能文案支持简体中文和英文。用户 / Agent 正文、代码、命令、路径、文件名、电脑名、供应商名称和协议身份保留原文。
- 设置在外观分区之后增加语言分区，选项为“跟随系统 / 简体中文 / English”。默认跟随系统；手动选择立即生效并本机持久化，未知偏好恢复跟随系统。按手机首个受支持的首选语言选择，所有 `zh` 地区 / 文字变体使用简体中文，`en` 使用英文，无匹配使用英文。系统模式在系统语言变化 / 回到前台时更新；手动选择不被系统变化覆盖。
- 切换仅更新呈现，不重建导航、Host 连接、消息身份、草稿、选择或滚动状态。不发送 Agent 命令，不修改其语言与模型设置。翻译只作用于应用拥有的文案模板，动态参数不参与翻译。
- 语言选项每项一行，复用现有材质、普通按钮轻压与选中标记（SC46 / MOT-25，ActionGlyph / M11 / M20）；保留至少 48pt/dp 命中区。长英文和大字体允许自然换行，不通过缩小字号隐藏内容。iOS 历史页标题在窄屏允许两行，以完整显示 History and branches；其余页标题默认单行，返回 / 筛选 / 下载命中区保持。系统权限提示采用平台语言资源。
- Android 权限提交按钮在等待电脑确认时允许完整自然换行；沿用共用按钮的字号、最小命中区和禁用状态，不截断确认状态，也不提前显示已生效。其他按钮默认行数保持。
- 双端翻译共享同一份模板清单及参数编号；生成产物必须可重复生成，校验缺失项、重复键和参数不一致。新增应用文案同步维护中英文。
- Host 提供的权限摘要 / 说明 / 选项和内置命令说明也属于界面文案。`mobile-host.json` 只列出已知文案与单个不透明参数的完整模板，允许对照已知中文或英文呈现；未收录的后端说明保留原文。手机不从 Agent 类型、权限值或选项 ID 推导含义，不修改设置 / 选项身份、可用性与执行路径。模型名、命令名、用户扩展说明及正文不进入该翻译入口；动态目录、未知权限和错误参数不递归翻译。

## 影响与验证

新增 S27；修订 S16、S19、S22；关联 S05、S08、S13、S25、M11、M20、V01–V03、V05–V08、V13。全端文案改动需执行既有双端 L1–L4、C01–C18、A1–A4，宽屏 A5，并比较同设备同配置基线。新增 R62：首次中文 / 英文 / 不支持语言启动、手动切换、重启持久化、回到系统、系统变化、窄屏长英文、辅助功能、保留草稿和原文。

单元测试覆盖语言解析、偏好回退、模板参数、双端目录一致性、Host UI 文案与不透明参数；设备测试覆盖设置选项、全局即时切换、导航 / 草稿保留，以及英文权限操作仍发送原 setting / option 身份。运行记录见 `.artifacts/ui-regression/20261104-app-language/summary.md`；设备阻塞不能记为验收通过。

## 2026-11-04 实施记录（验证中）

共享目录 1,481 条、iOS 核心 374 / 374、Android JVM 703 / 703 与双端 App / UI 测试包构建通过。用户追加模拟器测试后已实际完成同设备基线 / 候选全量；此前排队阻塞只作历史记录。画面发现并修复 iOS SE 英文历史标题单行截断、Android 权限等待按钮在 1.5 字体下截断；最终生产 App 上 iOS SE 和 iPad 语言专项各 3 / 3，Android 设置 A1–A4 整类共 32 / 32。系统语言启动、即时切换、重启持久化、原文 / 草稿及权限身份保留有自动证据。

Android 基线 183 项为 169 过 / 7 失败 / 7 assumption；最终生产 App 全量 192 项为 177 过 / 8 失败 / 7 assumption。7 项失败的异常首行和测试调用帧与基线一致；额外权限测试把 Compose 未使用的段落预留宽度误判为文字溢出，改为逐行边界、未省略、完整末字符与高度检查后，同一 App 的设置四组 32 / 32 通过，原全量失败仍保留。iOS SE 基线 89 项为 82 过 / 7 失败，候选 93 项为 82 过 / 11 失败；连接信息改用逐项短滚动，三个选择器按真实中文辅助功能组合标签匹配后，4 / 4 复测通过。其余 7 项中 5 项与基线断言及报错一致，长聊天工具展开的失败表现不同，另有同期回复卡片几何用例失败，均未解决；不能据总数声称失败集合未扩大。
