# ADR-0063：移动端中英文与系统语言

日期：2026-11-04

Status: accepted（用户授权整个 App；实施与设备验收分别记录）

## 规则

- S27 / r45：iOS 和 Android 的首页、目录、聊天界面、设置、配对、下载、文件审阅、交互面板、弹窗及辅助功能文案支持简体中文和英文。用户 / Agent 正文、代码、命令、路径、文件名、电脑名、供应商名称和协议身份保留原文。
- 设置在外观分区之后增加语言分区，选项为“跟随系统 / 简体中文 / English”。默认跟随系统；手动选择立即生效并本机持久化，未知偏好恢复跟随系统。按手机首个受支持的首选语言选择，所有 `zh` 地区 / 文字变体使用简体中文，`en` 使用英文，无匹配使用英文。系统模式在系统语言变化 / 回到前台时更新；手动选择不被系统变化覆盖。
- 切换仅更新呈现，不重建导航、Host 连接、消息身份、草稿、选择或滚动状态。不发送 Agent 命令，不修改其语言与模型设置。翻译只作用于应用拥有的文案模板，动态参数不参与翻译。
- 语言选项每项一行，复用现有材质、普通按钮轻压与选中标记（SC46 / MOT-25，ActionGlyph / M11 / M20）；保留至少 48pt/dp 命中区。长英文和大字体允许自然换行，不通过缩小字号隐藏内容。iOS 历史页标题在窄屏允许两行，以完整显示 History and branches；其余页标题默认单行，返回 / 筛选 / 下载命中区保持。系统权限提示采用平台语言资源。
- Android 权限提交按钮在等待电脑确认时允许完整自然换行；沿用共用按钮的字号、最小命中区和禁用状态，不截断确认状态，也不提前显示已生效。其他按钮默认行数保持。
- 双端翻译共享同一份模板清单及参数编号；生成产物必须可重复生成，校验缺失项、重复键和参数不一致。新增应用文案同步维护中英文。
- Host 提供的权限摘要 / 说明 / 选项和内置命令说明也属于界面文案。`mobile-host.json` 只列出已知文案与单个不透明参数的完整模板，允许对照已知中文或英文呈现；未收录的后端说明保留原文。手机不从 Agent 类型、权限值或选项 ID 推导含义，不修改设置 / 选项身份、可用性与执行路径。模型名、命令名、用户扩展说明及正文不进入该翻译入口；动态目录、未知权限和错误参数不递归翻译。
