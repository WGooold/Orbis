# ADR-0054：下一级整页统一导航与交互式返回

日期：2026-10-31

Status: accepted（用户确认页面盘点及范围后授权实施；完整设备与手动门禁按验证记录，不把实施等同于验收通过）

关联：[ADR-0051](0051-ui-style-motion-and-visual-stability-freeze.md) `2026-10-31/r24`，M07–M08、M14、V17–V18；[ADR-0053 §5](0053-settings-entry-page-motion-and-ui-regression-gate.md#5-设置下载与历史页的转场m14ui-04)。

## Context

页面返回效果过去逐页接入：聊天、设置、下载及历史与分支已有相同手势，但添加电脑在两端都未接入，Android 离线历史直接替换首页。iOS 还依赖一份页面白名单开启手势，新增页面容易漏接；Android 保留来源页面后，下层的系统返回处理器也需要统一管理。

用户要求先盘点，再把整页导航抽象为共用机制，覆盖当前可进入的所有下一级整页，并使后续新增整页默认继承相同效果。“下一级”是相对来源页的层级，不限定为导航栈的第二项。

## Decision

### 1. 通用行为

- 所有从现有页面打开的应用内整页，必须通过平台共用导航容器进入，默认具备 M07 的右侧滑入和 M08 的交互式右滑返回。不得维护手势页面白名单或在业务页面复制手势参数。
- 页面跟随右向横拖；短拖松手回弹，位移加约 0.15 秒速度预测超过约三分之一屏宽时完成返回；超出整屏用 0.18 阻力。沿用 M08 回弹、底层压缩和 0.34 遮罩，以及 Android 180ms 确认退场参数。本次不调整基线数值。
- 拖动露出直接来源页，完成后只退一层。按钮返回、系统返回与右滑遵守同一来源归属；多选的退出等页面内部返回语义保留，不能使后台来源页误处理系统返回。
- 来源页保留原实例及草稿、阅读锚点、跟随状态、搜索词、筛选、工具展开和消息身份；不能构建第二个聊天实例来模拟底层。预览在导航完成前不接受触摸或辅助功能操作；导航完成后来源页立即可操作。
- 取消、反向、快速重入和页面离开不得遗留遮罩或计时；正常动画、减少动画、系统关闭动画均保留相同返回目标和业务状态。竖向滚动与页面内横向控件继续各自消费手势。

### 2. 当前整页覆盖清单

| 路径 | iOS | Android |
| --- | --- | --- |
| 首页 / 会话目录 → 在线聊天 | 共用导航栈 | 共用页面容器 |
| 会话目录 → 离线会话 / 只读历史 | 复用聊天导航路径 | 从直接替换首页改为共用页面容器 |
| 首页 / 目录入口 → 设置 | 共用导航栈 | 共用页面容器 |
| 首页 → 下载 | 返回首页 | 返回首页 |
| 聊天 → 下载 | 返回原聊天 | 返回原聊天 |
| 聊天 → 历史与分支 | 返回原聊天 | 返回原聊天 |
| 历史与分支 → 下载 | 先返回历史，再从历史返回聊天 | 同左 |
| 侧边栏电脑菜单 → 添加电脑 | 纳入共用导航栈的默认手势 | 从直接替换页面改为共用页面容器，来源目录保留 |

目录入口在 iOS 原本先收起抽屉再进入整页，因此返回来源为首页；Android 原本保留目录抽屉状态，本次保留该平台行为。不能把底层显示成另一会话或空白占位来代替来源页。

### 3. 边界

- 首次配对引导是没有上一页的根页面，不启用右滑退出。已有配对后“添加电脑”是下一级整页，适用本规则。正在安全配对时保留现有操作阻断，手势不能绕过它。
- 新建会话、浏览电脑文件、扫码、会话权限 / 信息、完整消息、工具详情、远程交互及文件差异查看器保持当前 Sheet / 对话框呈现；不在此任务转换成整页。文件差异仍遵守 M13 的文件横向切换及标题区下拉关闭规则。
- 目录抽屉沿用 M09；页内进入文件夹仍是目录内容变化，不因此增加整页栈。
- 供应商管理遗留整页目前没有正常入口，iOS 只有预览路径、Android 只有闲置实现及组件测试。本次不恢复旧入口。若未来重新作为整页开放，同样必须通过共用容器。
- 系统文件选择器、分享、外部浏览器和系统设置由平台控制，不附加应用内返回手势。

### 4. 实现约束

- iOS `OrbisPageStack` 统一维护路径和每层来源快照；`push` 负责保存来源画面，`back` 只弹出栈顶，替换会话栈时清理旧快照。`navigationDestination` 默认包装 `OrbisPageTransition`，路由类型不再控制手势启用。根下一级可显示首页，深层使用来源快照，实际来源实例保留在原生栈中。
- Android `OrbisPageHost` 组合 `SwipeBackLayer` 与系统返回，并通过 `LocalPageActive` 让保留的来源页停止处理返回和手势；业务页面只提供开关、内容和返回动作。首页下一级的 `HomeOverlay` 覆盖聊天、离线历史、设置、下载、添加电脑；聊天内历史与下载也使用同一容器。
- 网络状态、配对与历史读取仍由原有模型负责；导航效果不代表配对、下载或源端操作成功。

## Verification

- Android `PageNavigationInstrumentedTest`：真实添加电脑入口的拖动几何、取消复位与返回后目录可操作；离线历史同款返回；嵌套系统返回只弹出顶部一层。已有 `SwipeBackInstrumentedTest`、`SwipeBackPagesInstrumentedTest` 和 `HistorySwipeBackInstrumentedTest` 保留。
- iOS `testAddComputerPageReboundsAndSwipesBack`：浅色正常动画、深色减少动画，短拖回弹，右滑返回后首页可操作。`testNestedPagesSwipeBackOneLevelAtATime`：聊天草稿、历史搜索词保留，下载→历史→聊天逐层返回。已有设置、聊天与下载返回用例保留。
- 手动专项 R19–R22、ID 映射及 C01–C18 / A1–A4 门禁见 [UI 回归方案](../testing/ui-regression.md)；本次页面盘点新增的自动用例已记录在 §3.3。验证记录位于 `.artifacts/ui-regression/20261031-page-navigation/summary.md`；未运行和失败项逐项记录，不以定向通过代替全量门禁。

本轮结果：Android 548 / iOS 223 项单元、双端构建通过；最终 Android 受影响组 11/11、iOS 导航 7/7 和目录手势 4/4 通过。Android 全量 138 项 11 失败，与导航修改前对照失败集合相同；iOS 全量 61 项 11 失败，9 项对照复现，配对等待与目录手势复跑通过。对照仅恢复导航代码并保留工作区其他修改；最终完整提交基线对照、手动冒烟、完整外观与窄屏门禁仍未完成，不能记为全部验收通过。

## Consequences

新整页只需接入导航容器即可继承统一行为，修复手势或参数时有共用入口。来源页面继续保留状态；模态与抽屉的交互边界保持清晰。新增 feature ID 为零，M14 扩展为通用整页规则，总计仍为 69 项。
