# ADR-0051：UI 风格、动效与画面稳定性基线

日期：2026-10-30；Status: accepted。当前基线：`2026-11-11/r57`。

保留共用材质、原生文本、稳定消息身份、阅读位置及平台手势。基线按需求演进，性能优化保持既有可见行为，新增 feature 使用新编号。

当前修订采用[统一设计与交互 ADR-0070](0070-unified-design-and-interaction.md)：四主题、连续深度、根标签、本地新建草稿、双圈供应商、三组设置及单行目录树。视觉、UX 与动效按[交互稿](../design/Orbis%20交互稿.html)对齐；业务确认、阅读稳定和可恢复操作继续沿用既有契约。实施、自动验证与用户验收分别记录。

登记 116 项（S 54、M 29、V 22、X 11）。历史交付与截图不代表本轮重验，实际验证与验收状态以本轮证据为准。
