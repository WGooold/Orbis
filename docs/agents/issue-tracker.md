# Issues and proposals

The canonical tracker is https://github.com/WGooold/Orbis/issues.
Use one issue per concrete problem, with expected/actual behavior and a reproducible example.
Do not include credentials, activation files, device identities, private conversations or unredacted logs.
Public design decisions belong in `docs/adr/`; use the vocabulary in `CONTEXT.md`.
Local experiments and diagnostics may use ignored `.scratch/` but must not be linked as public documentation.
