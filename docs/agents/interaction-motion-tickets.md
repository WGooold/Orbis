## MOT-01：共享动效基础

**实际问题**：Swift `Animation` 和 Kotlin `OrbisMotion` 仅有部分 token；不同页面直接指定动画、延时、坐标和清理。

**实现**：在双端 `InteractionMotion`、iOS `MotionGeometry.swift` 与菜单/发送模块集中 ADR 参数；提供屏幕锚点、触点观察、显示代次、取消 / 归零和 reduced-motion 统一路径。每类按语义命名，不把全部动作映射成一个 spring。

**验收**：新业务调用不含散落时长；失效 / 离页取消覆盖层；无重复触摸或辅助功能节点；减动画不等固定时长。纯函数测试验证最远角半径、裁切锚点、飞行路径、边缘返回几何与端点；避免只断言常量。

## MOT-02：首页左滑关闭连续

**场景 / feature**：SC01–SC02；M10、V11、V21。入口 `HomeView.closeSwipeGesture/runtimeCard`、`RuntimeListScreen` / `detectHomeCloseDragGestures`。

**复现**：卡片左拖越半宽，观察红底切灰及松手。数据先移除导致当前动画协程 / View 被销毁，卡片直接消失。

**目标与实施**：阈值文字 / 图形 / 底色 160ms 过渡；写入后在呈现层保留不可操作退场项，180ms 继续滑到屏外，160ms 收拢；取消、写入失败、Host 拒绝、断线、列表更新与换电脑按身份恢复 / 清理。不能用延迟提交换取动画。

**验收**：逐帧左向位置单调，未离屏不能折叠空位；每手势最多一次提交，每次进入 / 退出阈值各触觉一次，反复切换持续反馈，同侧移动与松手 / 取消回弹不追加；短拖和反向不提交；多选不响应左滑。扩展 `HomeSwipeCloseInstrumentedTest`、iOS 首页关闭 UI 用例及 outbox 恢复回归；手动 C09、R33，A1–A4。

## MOT-03：触点选择与工具栏形变

**场景 / feature**：SC02–SC05；S15、M06、M11–M12、V17、V21。入口 `OrbisSelectionButtonStyle/Indicator`、`NeumorphSurface/OrbisSelectionIndicator`，四种页面的顶栏。

**实际问题**：选择底色全卡淡入，首页三横线直接替换，按钮组无过渡。

**目标与实施**：非消费按下观察器记录本次触点；选中圆扩至最远角；首页线段旋转成叉、双按钮合并显示批量动作；目录、下载、遗留供应商复用固定槽形变。现有 7% 色、描边、标记槽、确认取消和无障碍选择保留。

**验收**：首帧中心接近触点≤4pt/dp；终帧全卡覆盖；逐项点击、长按、无障碍中心兜底；连续反选无残影；卡片边界与相邻卡 y 不变。扩展双端首页 / 归档 / 下载 / 供应商选择用例，新增 `SelectionMotion` 设备时钟中帧断言；C10–C13、R34，A1–A4。

## MOT-04：从锚点展开的菜单栈

**场景 / feature**：SC06–SC10；M18、S02–S03、S13、V17–V18。入口 `OrbisOverlay/MenuPanel/MenuItem`、`NeumorphMenu/MenuItem` 与调用方。

**实际问题**：只缩放淡入 / 平台默认动画，没有共用二级栈。

**目标与实施**：菜单根记录真实按钮矩形；自然尺寸安全区布局；二级先160ms改变形状、再220ms从右侧翻入；逆向返回、焦点恢复、栈顶 back、系统取消；目录电脑菜单拆根与电脑清单。保留供应商切换确认、当前电脑与红点语义。

**验收**：从屏幕四角 / 键盘上方 / 窄屏展开；进入返回各有中帧且同一表面；尺寸目标不是任意硬编码高度；连点、列表变化、换电脑关闭；系统 back 只退菜单一层。新增 `MenuMotionInstrumentedTest` / iOS 菜单 UI 用例；C11–C12、C18、R35，A1–A4。

## MOT-05：长按用户消息操作栏

**场景 / feature**：SC11–SC13、SC23；M19、S10、M05、V02–V03、V09、V12、V16。入口 `ChatMessageRow` / `UserMessageCard`。

**实际问题**：已确认用户气泡下方常驻复制、Rewind。

**目标与实施**：长按消息后在其上方展示横向操作栏，用共用锚点开合；复制成功反馈与计时在栏内；保留 pending 恢复区。激活时核查消息 / 会话归属及 Rewind 能力，维持原确认流程。历史 / 只读仅合法动作。

**验收**：没有下方常驻复制 / Rewind；长按与滚动、文字选择、链接、附件不争抢；阅读锚点≤1pt/dp；长消息、顶部边缘、键盘、历史预览都可操作。更新既有复制 / Rewind 测试的入口（不得删业务断言），新增长按/关闭/失效测试；C05、C15、R36，A1–A4。

## MOT-06：发送飞入

**场景 / feature**：SC14–SC16；M17、V02–V03、V09–V10、V17–V18；入口双端 composer 提交与本地 outbox 呈现。

**实际问题**：输入清空与气泡插入缺少空间连接，不能以全列表插入动画替代。

**目标与实施**：提交入口传准确 client id，测 composer 与目标气泡矩形，先70ms右移再210ms上移；非跟随 / 不可见时不滚动，向消息区边缘退隐。最大3个、无命中、离页取消；接受一次只飞一次，精确对账不重播；失败和队列保持事实。

**验收**：路径方向、终点≤4pt/dp、没有重复气泡；中文多行 / emoji / 附件 / 队列 / 快速连发 / 未连接 / 上翻阅读；扩展两端乐观发送用例，新增 `SendFlight` 纯几何和设备中帧测试；C05–C06、R37，A1–A4。

## MOT-07：最近提问右上出入

**场景 / feature**：SC17–SC18；S24、V01–V03、V06、V17；`ChatView` overlay、`ChatQuestionReminder`。

**实际问题**：现有160ms仅淡变，无方向，移除状态容易丢失离场内容。

**目标与实施**：220ms右上进入、160ms逆向退出；保存离场展示快照；显隐条件与最近问题身份沿用 ADR-0057。

**验收**：逐帧方向正确，通知覆盖和快速显隐不出现旧问题残留；点击仍定位原文、不恢复跟随；保留原4项 Android与2项 iOS专项断言，新增中帧、退出、减少动画断言；C05、R31、R38，A1–A4。

## MOT-08：所有可点击图标反馈

**场景 / feature**：SC18–SC27，兼及所有菜单 / 模态中的图标；M20、M02、M05、M12、M16。

**实际问题**：共用按钮只有材质按压；部分无样式按钮和图标文字按钮绕开组件。

**目标与实施**：给共用按钮语义角色和激活计数；下载箭头独立弹动、齿轮 / 历史旋转、其余轻弹；无样式 icon 按钮迁移或显式接同一修饰器。保持48命中及禁用语义；配额币 / 下载飞入已有专属效果去重。

**验收**：按 SC19–SC27 逐项记录入口，不仅截图首页三个图标；禁用 / 长按 / 拖动不误触，按下取消不执行；连点、导航离开、复制计时和 reduced-motion 正确。新增 `ActionGlyph` 设备时钟断言，保留已有复制 / 下载飞行 / 配额测试；C06–C08、C12–C15、R39，A1–A4。

## MOT-09：系统两侧边缘返回

**场景 / feature**：SC28–SC32；M08、M14、V13、V17–V18。入口 `OrbisPageTransition` / `OrbisPageHost/SwipeBackLayer`。

**实际问题**：Android普通 BackHandler 无手势进度；iOS自定义拖动只处理右移，顶部页面无边缘压缩。

**目标与实施**：接 Android predictive back 的开始/进度/取消/提交；iOS左右边缘反馈按用户补充作为可选增强，只有键盘/选区/横滚/Sheet兼容才保留，否则撤回新增行为并保留原返回；系统箭头与 App 指示按平台边界；压缩当前页并露出直接来源。共享返回协调器保证菜单、选择、IME、模态优先和一次提交。

**验收**：左右边缘短拖取消与完成，入场中接管，三层下载返回正确；草稿/搜索/阅读/展开不变；根页不错误退出，文件 Pager 和代码横滚不被抢。扩展 `SwipeBack*`、`PageNavigationInstrumentedTest` 与 iOS nested page 用例，新增系统手势夹具；C04、R19–R22、R40，A1–A4。
