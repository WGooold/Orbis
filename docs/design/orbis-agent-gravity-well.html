Agent 引力井

把 10 个 Agent 的启停，从一列开关改成一口以电脑为中心的引力井。每个 Agent 在环上有固定位置，离电脑越近越可用。沿经线拉进井口就是启用，推出井口就是停用；落在哪一圈，由电脑回报的真实状态决定。

协议轨迹

最新在上

    三条原则

    距离就是状态

    启用是你的意愿，安装、就绪、连接是电脑上的事实。两者不再挤在同一个开关里：越过井口表示启用，之后落在哪一圈由电脑回报。内圈已连接，中圈可启动，外圈需要处理，井外未启用。

    意愿先行，电脑定论

    手势只留下空心的待确认影子，电脑回执到达才落成实心。每个 Agent 各自等待，不锁住整组；冲突时回到电脑给出的位置，并在原处说明。

    停用是松手

    推出井口只撤销 Orbis 的接入，原生应用、终端和会话照常在电脑上运行。只有会中断运行中会话的同步时才确认，并写清是哪几个；其余直接生效，可在短反馈里撤销。

    距离即状态

    位置状态词外观何时
    内圈已连接凸起圆片，实心绿点；有运行中会话时绕行弧Orbis 接入已建立
    中圈可启动凸起圆片，空心点已安装或已配置，按需启动
    外圈准备中、未安装、待配置、接入失败、已暂停、恢复后生效凸起圆片，警告或危险点；准备中为灰色绕行弧已启用，但还不能使用开关保持已启用，错误单独显示
    井外未启用平面、细轮廓、退后未启用电脑不探测，也不显示其安装状态
    原位待确认、已排队空心圆片与强调色绕行弧；排队为虚线轮廓已发出或等待发出，未收到电脑回执

    手势与操作

    操作手机电脑说明
    选择点 Agent；在井面横向拖动转盘；在卡片上左右滑点击；方向键选中项转到 12 点钟的槽口。槽口就是这一项的开关轨道，卡片同步切换
    启用沿经线拉进井口，或卡片开关、列表行拖入，或开关、Enter越过井口时井沿亮起并有一次轻触觉；未越过就松手则弹回
    停用沿经线推出井口，或开关同左有运行中会话时确认并列出会话；没有则直接停用，短反馈可撤销
    批量顶栏切换到列表标题栏「轨道 / 列表」列表行就是开关，适合首次一次开多个
    处理外圈项的 info 说明去电脑上处理检查器只给一个下一步：安装、应用配置或重试App 不改安装、凭据和配置，与 ADR-0094 §01 一致

    反馈与边界

    情况表现依据
    等待回执每项各自显示待确认；后续操作排队，收到回执后按新修订号逐个提交ADR-0094 §04现行实现锁住整组；改为逐项等待需同步修订
    修订冲突回到电脑结果，轻摇一次，原位显示「电脑上刚有改动，未应用」§04 不静默覆盖
    他端修改平滑移到新位置，原位来源标签停留 4 秒：「电脑上启用」「Pixel 9 上停用」需要快照增加可选 origin 字段，按 ADR-0064 协商未协商时显示「其他设备已更改」
    电脑复核手机还不知道的新会话由电脑要求确认，App 再弹出确认§03 由 Host 在应用时复核
    回执丢失、重连先读快照，不重放；未确认的意愿回到电脑结果，并标「未提交，已按电脑同步」§04
    电脑暂停井失去引力：已启用项漂到外圈并显示已暂停。电脑端仍可改，新启用项显示「恢复后生效」；手机显示已暂停，不能修改§03 运行时切换
    手机离线井面冻结、去色，显示上次同步时间；开关锁定§04 不接受离线编辑
    接入失败留在外圈，危险点和原因；开关仍为已启用；电脑端给出重试§04 启用与接入错误分开
    旧版电脑只显示电脑公告的 Agent，没有井外与开关；顶栏 info 说明§04 兼容
    全部未启用全部在井外；槽口里的那一项下探两次作为手势提示；电脑概览的 Agent 卡直接给「启用 Agent」§03 无启用项的入口
    减少动画去掉转盘、迁移与下探，直接到终态；绕行弧静止设计规范第 9 节

    与现状对比

    现在提案
    入口电脑：Agent 页下方的「启用 Agent」开关组；手机：设置里 10 个平铺开关一口井同时表达意愿与事实；设置里一行入口，带迷你井
    状态开关只表达启用，安装和接入在别处位置表达状态，卡片给出四级状态梯
    提交中整组开关禁用，下方一个转圈每项各自待确认，可以连续操作
    停用确认手机每次都确认，不说影响只在影响运行中会话时确认，并列出会话
    多端开关静默跳变平滑移动并标出来源
    双生来源Codex、DeepSeek 的终端版与桌面版各占一行，看不出关系相邻经线、终端与桌面角标，卡片里互相跳转，共用供应商一目了然

    落地

    共用组件

    • 引力井：Compose Canvas、SwiftUI Canvas、QML Shape 各一份，几何比例共用（圈半径 0.163 / 0.256 / 0.343 / 0.445 × 井径）
    • 意愿开关：在现有 NeuToggle / SoftSwitch 上增加待确认、已排队、锁定三态
    • 状态梯：启用、安装或配置、就绪、连接四级
    • 来源标签：复用 ADR-0083 F2 对象原位反馈

    数据与协议

    • 只读现有 agent.enablement.snapshot / result 与接入投影（ready、runtimeCount、错误）
    • 环上顺序取 Host 目录顺序；未知来源追加经线并用通用符号
    • 核心交互不新增帧；来源标签需要快照可选 origin；逐项等待需要修订 ADR-0094 §04 的 App 行为
    • 不变：Host 唯一事实来源、修订号与冲突、停用由 Host 复核、旧端兼容、关闭项不探测
