环港 · 港务

Agent 启用与停用的提案，延续「环港」。电脑是港口，每个 Agent 是一艘船：从锚地拖进内环就是启用，拖回锚地就是停用。进了港的船停在内环各自的泊位上，船上的航行灯和引擎按电脑回报的真实情况亮起。

三条原则

入港是决定，灯火是事实

拖进内环或在名册里打开，只回答“要不要接入”。安装、就绪、连接是电脑上的事实，由船上的航行灯、引擎和尾迹表达，不再画圈。锚地里的船在暗处，只留一盏停泊灯，电脑也不去探测它。

电脑放行才算数

松手后船悬停在放下的位置，它的泊位射出一道牵引光等电脑回执；回执到了，船沿弧线航线点火靠泊、减速，泊位两侧的灯换成它的颜色。每艘船各自排队，冲突时牵引光熄灭、船回到锚地。

离港只收 Orbis 的缆

原生应用、终端和电脑上的会话照常运行。没有会话时直接离港，提示里可撤销；有会话时拖动更沉，松手后列出会停止同步的会话再确认。会话不删除，重新入港后按原样回到轨道。

一艘船读懂状态

位置状态词表现
锚地未启用暗处的船体，一盏白色停泊灯缓慢呼吸
内环中待确认悬停，泊位射出流动的牵引光
内环中已排队悬停，牵引光暗且不流动
泊位准备中白色航行灯从舰首到舰腹依次扫过，引擎点火
泊位未安装 · 待配置引擎熄火，琥珀灯慢闪
泊位接入失败引擎熄火，红灯快闪，船底泛红；仍是已启用
泊位可启动白色舰首灯常亮，引擎低功率
泊位 / 轨道已连接绿色舰首灯、白色频闪、引擎；退出港务后带着会话回到轨道
全港恢复后生效电脑暂停：泊位灯转琥珀，站灯减半，船静止

手势

操作做法
进入港务点左上角电脑名；首次使用点「开放泊位」；出港面板底部的「锚地」。已启用的船从轨道飞回各自泊位
启用把锚地的船往上拖进内环：泊位灯带加速亮起，它的泊位打出聚光，提示「松手入港」；也可以直接点它
停用把泊位上的船拖向锚地：牵引光变红，锚地边沿亮红；有会话时船更沉
查看港务中点泊位上的船：状态梯、会话、同族来源、下一步
读屏与批量「名册」逐项开关，读出名称、状态词和会话数

相对现行实现的改动

  1. 逐项排队写入。现行一次只允许一个待确认，整组开关禁用。改为 App 端串行队列，按上一份回执的修订号逐个提交；冲突只撤回该项，排队中的其他来源继续提交。
  2. 停用只在有会话时确认。现行每次停用都弹窗；改为无会话直接生效并提供撤销，Host 应用时仍复核。
  3. 接入状态进 App。准备中、未安装、可启动、已连接、失败需要 Host 的接入投影；未下发时船只按启用与否显示，不臆测。
  4. 他端来源标签。「电脑上启用」「Pixel 9 上停用」需要快照增加可选 origin，按 ADR-0064 协商；未协商时显示「别处」。
  5. 边界保持不变。离线只读并标明上次同步；旧版 Host 没有锚地，沿用原公告；新建、出港和概览只列已启用来源。
