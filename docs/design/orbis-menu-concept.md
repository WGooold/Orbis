# Orbis Soft Pop — Mobile 03 / Little ideas, big orbits

入口：[独立 HTML 设计稿](orbis-menu-concept.html)。双击即可在电脑浏览器打开；HTML、CSS、JavaScript 和 SVG 全部内联，无服务、账号、字体下载或外部网络依赖。电脑上显示手机画布，窄窗口显示全屏手机布局。

这版以用户明确要求的**大胆创作**为目标：最初四张彩色叠卡构成工作空间入口，粗体大字、轨道机器人插画、柔影和内凹控件形成统一风格，INTEGRATIONS 保留倾斜拨卡。基本操作沿用已验证的会话状态逻辑，页面组织和内容表达按新的手机体验重新设计。原生用法审计作为功能参考，见 [入口、供应商与新建审计](orbis-native-usage-audit.md) 和 [聊天使用路径审计](orbis-chat-usage-audit.md)。

## 创作方向

- **四色工作空间**：紫色 SESSIONS、薄荷绿 PROJECTS、珊瑚色 ARCHIVE、黄色 LET’S MAKE SOMETHING 连续压叠，保持初版的大字、圆角和色块比例。一次展开一张，卡片自然增高，其他卡片随之移动；收起内容退出键盘焦点与触摸命中。
- **预览与深入**：展开后先看最近会话、工作目录或归档预览；点条目直达，底部文字进入完整目录。返回时保留原来的叠卡区域，完整目录的多选状态不带回预览。
- **带行动的首页插画**：小机器人和轨道成为黄色主卡的视觉中心。存在待审批会话时显示 A LITTLE HELP HERE 并直达；其他情况下提供继续会话或开始新会话。
- **手机操作节奏**：叠卡展开、完整页面侧向进入、新建面板从底部展开，供应商卡片沿倾斜轨迹拨动。常规高度展示完整四色菜单；小屏允许滚动，底部电脑和设置入口固定。
- **可见的创建入口**：黄色卡和首页珊瑚色按钮都进入带黄色顶部边缘的新建面板；Agent 选择使用黄色高亮，目录直接浏览。

本稿用独立样式演示设计探索，不将新创作参数写入原生 r48 基线或已验收计数。

## 建议体验路径

1. **先看首页与叠卡**：首页黄色插画卡优先带你处理待审批事项，下方保留打开的会话。左上菜单展开四色卡组，点标题切换预览；PROJECTS 点目录进入该目录，SESSIONS / ARCHIVE 的底部入口进入完整列表。搜索在叠卡上方；Agent 筛选、归档开关和多选操作在完整目录内。
2. **体验倾斜卡组**：首页右上设置 → INTEGRATIONS → 选择 Agent → 上下拨动配置卡 → 应用。卡片是该 Agent 保存在电脑上的配置，滑动只浏览。支持触摸、鼠标拖动、滚轮、方向键、箭头和点按露出的卡片；短拖/取消回到原选择，首尾循环。
3. **创建一个会话**：首页新建 → 选 Agent → 浏览电脑文件夹 → 在此目录新建。目录旁的加号直接预置目录；模型和权限进入聊天后再选。启动期间可先写草稿；返回不取消启动。新建名称来自首次输入。
4. **查看运行状态**：Claude 示例正在等待审批；DeepSeek 示例正在运行。运行中输入可排队，非 Claude 还可以选择 steer；空输入时按钮变为停止。队列可以撤回，审批卡单独回答。
5. **查看历史与恢复**：目录中的旧会话先显示只读历史，点“在电脑继续会话”才恢复。Codex 的工作区旧会话需要先切到匹配 provider。归档项需要先取消归档。
6. **试试边界情况**：设置或会话菜单 → 演示情境，可切换离线、结束示例任务，或令下一次发送/配置/启动返回明确失败、未确认。未确认提供核对，不自动重发。
7. **切换电脑与下载**：电脑面板里切到离线 Home PC，查看缓存和禁用状态；下载页支持暂停、继续、取消、删除任务，已完成示例可以实际保存为本地文本文件。

手机导航包括左缘右滑进入抽屉或返回上页、抽屉左滑收起、把手下滑关闭面板、左滑空闲运行卡关闭、长按进入多选。Escape 顺序为面板、子页、选择模式、抽屉。底层页面使用 inert，键盘焦点留在当前表面。聊天保留草稿和阅读位置，回到顶部阅读时不会被下一次更新拉到底部。

## 这次纠正的功能关系

| 用户看到的内容 | 含义与操作 |
| --- | --- |
| 当前电脑 | 所有列表、目录、供应商和下载的归属，不是会话 Agent 筛选 |
| 首页卡片 | 已打开的 Runtime；关闭后 Session 历史仍保留 |
| 目录彩色卡片 | 真实 cwd 的会话集合，没有强造“项目”对象 |
| 五个新建 Agent | Pi、Codex 终端、Codex 桌面版、DeepSeek Harness、Claude Code |
| 四组供应商配置 | Pi、Codex、Claude、DeepSeek；没有单独 Desktop provider 组 |
| 供应商卡片 | 已保存 profile；浏览与应用分开，不改会话 Agent，不筛选目录 |
| Pi 启用状态 | 各卡独立启用/移除；其他已启用配置保持，Host 示例卡片保留 |
| Codex 历史 provider | 比较原生 provider 键，不比较 profile ID；不匹配时不自动切换或改写历史 |
| 停止 / 关闭 / 归档 | 分别作用于主回合、运行实例、持久会话目录 |
| 模型 / 思考深度 / 权限 | 会话配置，等待示例回执；权限变更不覆盖模型选择 |
| 后台任务 | 只读活动列表；主回合空闲仍能输入，存在后台任务时禁止关闭 |
| 历史树 / Git 分支 | 前者预览会话路径，后者只读 cwd 的 Git HEAD；Rewind 不撤销代码 |

供应商切换有忙碌限制。Claude 在运行或等待审批时不能切换；Codex 桌面版已接入时阻止 Codex 配置切换。Codex 切换后会话需重新打开；Claude/Pi 需要重开才加载新配置。配额只展示当前支持的官方示例配置，表示**剩余配额**，未知不是零。

失败的新建保留本地启动卡与草稿，成功前不混入正式历史目录。同一电脑有待完成启动时限制重复新建。启动失败前等待的输入转为失败消息，重新启动不会隐式重新发送；用户可以恢复草稿后明确发送。

## 演示范围与原生差异

全部电脑、会话、能力清单、进度、回复和回执均为本地模拟数据；刷新重置业务状态，只有明暗偏好会在浏览器允许时保留。HTML 不连接真实 Host，不执行命令，不读取密钥或真实电脑目录。演示情境属于设计稿控制，不是原生产品功能。

以下是明确的设计选择或压缩范围：

- 原设置当前路径通过菜单点选立即提交 profile；本稿改成倾斜卡浏览加显式应用，保留等待确认的语义。
- 原 Android 点击非在线历史通常直接恢复，iOS 优先缓存阅读。本稿采用缓存预览后显式继续，并在目录菜单保留继续入口。
- 原生 Agent/模型/权限/Slash 能力来自 Host。本稿使用有限示例能力集合，不能把展示的模型名称或菜单当成所有后端都支持；“会话权限”不是统一的 `/permissions` 命令。
- 配对仅演示“扫码→等待电脑确认”；不调用相机、真实二维码解析、端到端加密或网络重连。外观只演示深浅色，未实现原生的全部主题/语言设置。
- 附件只在本机保留文件名与消息关联，不上传或读取文件正文。纯附件与运行中附件按完整目标路径演示；Android 当前存在的源码差异已在聊天审计明确记录。
- 输入演示等待确认、等待启动、已排队、落地、明确失败、未确认及恢复/核对。没有复现完整原生事件账本、分页对账、断线回执乱序、所有审批表单与自动压缩重试矩阵。
- 工具、diff、历史树、Git 和电脑文件浏览为有限只读示例；未实现大型树搜索、分页工具正文/导出、全部多文件 diff、真实远端文件系统。历史节点点击只预览；消息 Rewind 有明确确认，Codex 在当前会话回退，DSH 示例创建分支会话。
- 下载为本地模拟任务；保存示例通过浏览器文件下载。没有真实断点续传、校验或系统分享。这也不代表 Android 已实现 iOS 的完成文件 ShareLink。
- 未确认配置核对使用预设的“电脑仍保留旧配置”结果；其他结果和服务器冲突不是这个离线稿的完整覆盖。
