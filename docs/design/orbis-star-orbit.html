ORBIS 交互概念

星轨

从手机看自己的电脑：电脑是恒星，Agent 是绕它运行的行星，会话是行星的卫星。光信号就是手机与电脑之间往返的消息。

对应关系

恒星
一台电脑。色温随系统：macOS 暖白，Windows 冰蓝，Linux 橙红。离线时冷却成暗星，行星停止发信号。
行星
一种 Agent。夜面亮起的纹路是它正在做的事，越忙越亮。
卫星
一个会话。所有会话都是同一种多面水晶灯，和 Agent 的材质分开；灯芯是所属 Agent 的颜色，运行中明亮并拖出轨迹，等待审批变琥珀色，空闲时只剩微光。
消息
在电脑内部，Agent 用自己的介质说话：Claude 是窑火余烬，Codex 是一个个字符，Pi 是三色积木，OpenCode 是小方框，OpenClaw 是气泡，DeepSeek 是钴蓝墨滴，Kimi 是月牙。离开电脑后，消息一律封进 Orbis 胶囊；局域网直达，中继连接在中继处停一下再原样转发。
五种消息
指令：一颗白胶囊进来，在 Agent 处化成淡色介质送到会话。输出：一串介质从会话流出，到电脑打包成胶囊回到手机，越长胶囊越多。工具调用：在 Agent 与电脑之间绕一圈，去时淡、回时满。审批：琥珀胶囊停在手机身边绕行，处理后才返回。心跳：一圈微光沿连接来回。

四个层级

星图（所有电脑、它们的 Agent 和这台手机）→ 电脑 → Agent → 会话。在星图上手机是网络里的一个节点；进入电脑之后，光流改为朝屏幕底部，也就是朝你流来。层级之间按对数距离推进，同层之间沿轨道拉远再推近；越靠近会话，轨道越慢，方便阅读。

七个 Agent 世界

Claude Code
窑火机器人。照它的像素小机器人用上釉陶土方块砌成，眼睛是两扇窑火窗；会踱步，忙起来头顶的方块会飘起来。
Codex
黑云终端。一团漆黑的釉面云朵，边缘泛青，外圈缠着滚动的终端输出。
Pi
π 积木。三块漆面积木拼成 π，干活时彼此推开又合拢。
OpenCode
方框门。钛金属铸成的方框，框里是一扇会亮的门和闪烁的光标。
OpenClaw
红壳小怪。糖漆红壳、青色眼睛，钳子随任务开合，偶尔眨眼。
DeepSeek
青花鲸。品牌蓝釉的鲸背，鲸腹画着青花海水纹，尾鳍随任务摆动。
Kimi Code
月之暗面。布满环形山的月球，背光的一面刻着发光的 K，那颗蓝点绕着它转。
