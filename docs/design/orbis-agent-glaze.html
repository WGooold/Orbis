Agent 釉池

选用哪些 Agent 是低频操作，一台电脑往往只设置一两次，所以这一版把启停做成一个值得记住的瞬间。电脑是一汪釉，每个 Agent 是一颗瓷珠：放进釉池就是启用，从池里提出来就是停用。釉有没有包住珠子、亮不亮、冒不冒泡，都按电脑回报的真实情况显示。

    三条原则

    放进去是决定，包住才是事实

    松手只把珠子挂到池边，釉托住一半，转圈等电脑回执。回执到达时釉才一口包住它，涟漪荡开，颜色在釉里晕开，触感也在这一刻给出。每颗珠子各自等待；冲突时珠子回到电脑给出的位置。

    电脑的形状就是你选的 Agent

    釉池等于电脑加上已启用的 Agent。多放一颗，釉流过去多占一格；提走一颗，釉退回来。没启用的珠子是素坯：不上釉、不发光，电脑也不去探测它。

    拿出来要用手提

    停用要把珠子从釉里提起来。没有会话时颈一拉就断，短反馈里可以撤销。有会话时釉更稠，拉出一根粗颈，气泡被扯进颈里；越过卡位列出会受影响的会话，松手才停用。只提走 Orbis 的接入，原生应用和会话照常运行。

    第一次

    1. 0 s
      打开

      上排 10 颗素坯珠子卧在各自的小窝里，哑光、带细微颗粒，标识像刻在坯上；下面只有电脑那一小汪釉。

    2. 1.1 s
      邀请

      釉池朝第一颗珠子伸出一条触角，够不着就缩回，再来一次。减少动画时不做。

    3. 拖动
      釉来接

      珠子靠近釉池时，釉流出来接；再近一点被吸住，状态词换成「松手启用」，轻触觉一次。还没被吸住就松手，珠子回到窝里。

    4. 松手
      挂在池边

      珠子落到它的位置，釉托住一半，右上角转圈。这时可以接着放别的珠子，每颗各自等待。

    5. 约 0.4 s
      电脑确认

      釉一口包住珠子（spring-pop），涟漪从落点荡开，Agent 的颜色在釉里晕开再退去；第一颗会晕满整池。珠子从哑光素坯变成上了釉的白瓷，标识显出颜色，触觉在这一刻给出。

    6. +1.3 s
      接入

      准备中，一道光绕着珠子流转；就绪后停下。已连接时珠子下方透出 Agent 色，每个运行中会话是一个缓缓上浮的气泡。

    一颗珠子读懂状态

    状态词珠子釉何时
    未启用哑光素坯，带细微颗粒，标识像刻在坯上；卧在窝里无默认电脑不探测，也不显示安装情况
    待确认、已排队挂在池边；转圈表示已发出，空心点表示排队托住一半已发出或等待发出，还没收到电脑回执
    准备中、安装中包在釉里一道光绕珠子流转电脑正在准备接入
    未安装、待配置右下角挂下载或配置章包住启用了，但电脑上还缺东西点珠子查看下一步
    接入失败右下角挂红色叹号章包住开关保持已启用，错误单独显示
    可启动上了釉的白瓷，标识显出颜色、像画在釉下，表面一点高光包住，不发光已安装或已配置，按需启动
    已连接同可启动珠子周围透出一圈 Agent 色；每个运行中会话是釉里一个上浮的透明气泡Orbis 接入已建立
    已暂停、恢复后生效失去光泽；恢复后生效挂时钟章凝住，涟漪和气泡停下电脑暂停中

    手势与操作

    操作做法说明
    启用把素坯珠子拖进釉池，或点它拖近时釉流出来接，被吸住后状态词换成「松手启用」，轻触觉一次。点一下，珠子自己划一道弧跳进池里
    停用把池里的珠子往外提没有会话时提出一段松手，颈断开，珠子回窝，短反馈可撤销。有会话时釉更稠，越过卡位列出会话、状态词换成「松手停用」，松手才生效，退回卡位内则取消
    不拖动时的确认详情里的开关、读屏操作有会话时珠子不动，原处弹出确认：列出会话，「保留」或「停用」
    查看点池里的珠子手机弹出详情卡片，电脑在下方检查器显示从属设置；查看不改变状态
    处理点挂着章的珠子电脑检查器只给一个下一步：安装、应用或重试；App 只说明去电脑上处理
    键盘与读屏每颗珠子是一个开关读出名称、状态词和会话数；空格切换，回车看详情，方向键在珠子间移动
    触觉只在三处：被釉吸住、越过卡位、电脑确认包住珠子。冲突退回不震动

    反馈与边界

    情况表现依据
    等待回执每颗珠子各自挂在池边等待；后续操作排队，收到回执后按新修订号逐个提交ADR-0094 §04现行实现锁住整组，改为逐项等待需同步修订
    修订冲突珠子回到电脑给出的位置，上方显示「电脑上刚有改动」§04 不静默覆盖
    其他设备修改珠子自己跳进池里或被提起，来源标签停留 4 秒：「电脑上启用」「Pixel 9 上停用」快照需要可选的 origin 字段，按 ADR-0064 协商未协商时显示「其他设备已更改」
    电脑复核手机还不知道的新会话由电脑要求确认：珠子回到池里，原处列出会话§03 由 Host 在应用时复核
    回执丢失、重连先读快照，不重放；未确认的珠子回到电脑结果，并标「未提交，已按电脑同步」§04
    电脑暂停釉面凝住、失去光泽，涟漪和气泡停下。电脑上仍可放入，新珠子挂时钟章，恢复后生效；手机不能修改§03 运行时切换
    手机离线整池去色、冻结，显示上次同步时间；珠子提不起来§04 不接受离线编辑
    旧版电脑没有珠子窝，只显示电脑公告的 Agent，珠子不能提起；顶栏 info 说明需要更新电脑端§04 兼容
    减少动画没有弧线、涟漪、晕色和气泡，珠子直接到终态；转圈停住设计规范第 9 节
    着色器不可用退回静态圆角块与常规阴影：没有釉颈和涟漪，其余交互不变Android 8 到 12、WebGL 关闭时

    与接线台对比

    接线台釉池
    第一次插头插进插孔，咔哒一声珠子落进釉里，涟漪和颜色铺满整池
    看全局10 根线逐行排开，状态靠线和灯池子的形状就是已启用的集合，一眼看出接了几个
    停用的分量拔出时有阻力，越过卡位釉的黏稠度随会话数变化，颈越拉越细
    占用每个 Agent 一整行素坯一排，池子按启用数长高
    实现普通矢量绘制一个片元着色器；需要静态退路

    落地

    渲染

    • 一个着色器：釉池是电脑与各 Agent 圆角格的平滑并集，珠子是穹顶，成对软阴影由偏移采样得到，光从左上，与 raised / inset 令牌一致
    • iOS 17+：SwiftUI layerEffect 加 Metal 着色器；文字和标识仍是普通视图
    • Android 13+：AGSL RuntimeShader；Android 8 到 12 退回静态圆角块
    • Windows Host：QML ShaderEffect
    • 只在动画期间逐帧绘制，静止时保留最后一帧；弹簧沿用 spring-page、spring-pop

    数据与协议

    • 只读现有 agent.enablement.snapshot / result 与接入投影（就绪、运行数、错误）
    • 珠子顺序取 Host 目录顺序；未知来源追加一颗，用通用符号
    • 核心交互不新增帧；来源标签需要快照的可选 origin；逐项等待需要修订 ADR-0094 §04 的 App 行为
    • 不变：Host 唯一事实来源、修订号与冲突、停用由 Host 复核、旧端兼容、关闭项不探测
