Agent 转盘

供应商页改名为 Agent 页，转盘多管一件事：启停。内圈选 Agent，外圈选供应商，两圈之间加一根插销。把插销推出去，Agent 接通外圈，就是启用；拉回来就是停用。电脑上不用转盘，内外两圈拉直成左右两栏，插销变成点一下就能完成的开关。

手机：沿用现有双环转盘与手势电脑：两栏面板，鼠标与键盘优先沿用 ADR-0094 启用协议，不新增帧沿用 r58 材质、动效与文案规范

协议轨迹

最新在上

    三条原则

    上下是挑，左右是开关

    转盘原本只用上下拖：内圈挑 Agent，外圈挑供应商。启停用上空着的横向：插销沿半径推出去，接通外圈就是启用；拉回内圈就是停用。手势方向在起手 8 pt 内锁定，横拖不会误转盘。

    插销是决定，外圈是事实

    插孔留给电脑：拖动时插销最远只到插孔前，再推只有很重的阻尼；松手就停在那里，空心并转圈，不会后退。电脑回执到达后，插销一次落进插孔，落到底的同一刻外圈从指针处向两侧亮开、触感给出，只有这一拍。回执一到，外圈就是最终的样子：有供应商的立刻列出，主按钮直接是「正在使用 X」；之后的准备、就绪、失败只改变名牌上的状态词和指针颜色，画面不再重排。

    拉回只断 Orbis

    拉回插销只撤销 Orbis 的接入，原生应用、终端和会话在电脑上照常运行。有运行中会话时先列出会受影响的会话再确认；没有就直接停用，短反馈里可以撤销。

    一根插销读懂状态

    状态词插销（手机）／开关（电脑）外圈底部主按钮
    未启用停在内圈，平面、去色断电：外圈压低，刻度变淡，指针空心，只显示 Agent 名与「未启用」电脑不探测，也不显示安装情况启用 Hermes Agent
    待确认、已排队停在插孔前，空心并转圈；排队为虚线拖动的极限就是这个位置，松手不回退保持原样，不预先亮起正在启用／正在停用，不可点
    准备中、安装中到底通电并列出供应商，名牌下方标注「准备中」；一段光沿外圈循环与就绪后相同，不出现过渡文案
    未安装、待配置到底，警告点通电；有供应商的照常列出，名牌下方标注状态；无供应商时状态词旁 info 说明去电脑上处理同上
    接入失败到底，危险点通电；原因显示在主按钮上方开关保持已启用，错误单独显示同上
    可启动、已连接到底；空心点／实心绿点通电。有供应商的 Agent 列出供应商，与现在一致；其余只显示状态切换到 X／正在使用 X；无供应商时为「已启用」
    已暂停、恢复后生效到底，灰点；手机上锁定通电但不流动不可点

    手势与操作

    操作手机：转盘电脑：面板说明
    选 Agent上下拖内圈；点图标点左栏行；↑↓内圈从 4 个扩到全部 10 个，按 Host 目录顺序，启停不改变位置
    挑供应商上下拖外圈；点名字点行预览；双击或「切换」浏览不提交，提交走主按钮，与现在一致
    启用插销向外推过半程后松手；或主按钮「启用 X」点插销开关；空格；右键菜单过半程时轻触觉一次，状态词变「松手启用」；没过半程就松手则弹回
    停用插销向内拉过半程后松手同上有运行中会话时先列出再确认；否则直接停用，短反馈可撤销
    批量无Shift／⌘ 多选，左栏下方出现批量条首次使用一次开多个；批量停用合并成一次确认
    手势提示点插销：探出一小段再退回，状态词短暂变为「向外推启用」悬停：插销朝目标方向偏移 5 px不加常驻说明文字
    键盘与读屏→ 启用，← 停用，空格切换；读屏把插销读作开关，并提供「启用／停用」操作↑↓ 选择，空格切换，Esc 取消多选主按钮「启用 X」也是无障碍兜底

    电脑为什么不用转盘

    转盘靠手指连续拖动弧线，鼠标拖弧线既慢又不准。电脑面板保留同一套关系：左栏就是内圈，右栏的供应商列表就是外圈，选中指针变成行首的小三角，插销变成一次点击的开关。

    转盘面板为鼠标做的改动
    内圈左栏 10 行一屏看全，不用转；行内状态词常驻；双生来源（终端／桌面）用左侧细线连起来
    插销行尾的插销开关点一下即可，不要求拖动；悬停时插销朝目标方向偏一点，预示点下去会发生什么
    外圈右栏的供应商列表滚轮浏览，悬停出现「切换」；当前项行首三角并附配额；有运行中会话时在按钮旁就地确认
    主按钮详情头部未启用时右栏只剩一个「启用 X」；已启用时依次是待处理事项、供应商、运行中会话、接入设置
    （无）多选与右键Shift／⌘ 多选后批量启停；右键菜单含启停、供应商配置、复制诊断信息

    与现状对比

    现在提案
    手机入口底部标签「供应商」，转盘只有 4 个 Agent；启停在 设置 › Agent 的 10 个开关里底部标签改名「Agent」，转盘列出全部 10 个，启停与供应商在同一处完成；设置里的 Agent 分组改成一行，跳到 Agent 页
    电脑入口「你的 Agent」卡片、下方的「启用 Agent」开关组和单独的供应商页一个 Agent 面板：左栏启停，右栏供应商、接入与会话
    电脑概览Agent 行的手机状态只在圆点悬停时可见；没有整体进度；手机只显示数量状态词常驻；未完成设置时有 5 步引导条；设备条列出每台手机与路径；行点击直达 Agent 页
    提交中整组开关禁用每项各自待确认，可以连续操作
    停用确认手机每次都确认，不说影响只在影响运行中会话时确认，并列出会话
    批量无电脑端多选启停
