Agent 接线台

把 10 个 Agent 的启停做成一块接线台。每个 Agent 一根线，把插头插进电脑的插孔就是启用，拔出来就是停用。插头只表示你的决定；线有没有绷直、灯亮不亮、线上有没有打结，都按电脑回报的真实情况显示。

协议轨迹

最新在上

    三条原则

    插头是决定，灯和线是事实

    启用是你的决定，安装、就绪、连接是电脑上的事实。插头只回答要不要接入；灯、线和线上的结回答现在能不能用。没插上的线不通电，电脑也不去探测它。

    咔哒一声由电脑给出

    松手只把插头送到插孔口，带着转圈等待；电脑回执到达才咔哒插到底，触感也在这一刻给出。每根线各自等待，不锁住整块板；冲突时插头退回电脑给出的位置。

    拔掉的只是 Orbis 的线

    拔出只撤销 Orbis 的接入，原生应用、终端和会话照常运行。线上有光点说明有运行中的会话：这时往外拔会有阻力，越过卡位就列出会受影响的会话，松手才停用。没有光点就直接拔下，短反馈里可以撤销。

    一根线读懂状态

    状态词插头线灯何时
    未启用停在名牌旁，空心点盘成弹簧不亮默认电脑不探测，也不显示安装情况
    待确认、已排队停在插孔口；转圈表示已发出，空心点表示排队虚线不变已发出或等待发出，还没收到电脑回执
    准备中、安装中插到底微松，一道流光扫过转圈电脑正在准备接入
    未安装、待配置插到底松着，中间打一个结警告点启用了，但电脑上还缺东西点结查看下一步
    接入失败插到底松着，红色的结危险点开关保持已启用，错误单独显示
    可启动插到底绷直空心圈已安装或已配置，按需启动
    已连接插到底绷直，Agent 色，有电流；每个运行中会话是一个光点实心绿点Orbis 接入已建立
    已暂停、恢复后生效插到底下垂；恢复后生效挂一个时钟结空心圈电脑暂停中

    手势与操作

    操作手机电脑说明
    启用把插头向右拖进插孔，或点插头向上拖进插孔，或点击、空格拖近孔口时插头被吸住、孔沿亮起，状态词换成「松手启用」，并有一次轻触觉。还没到孔口就松手，线会把插头收回去
    停用把插头拖出插孔，或点插头向下拖出没有会话时过半松手即停用，短反馈可撤销。有会话时拖动有阻力，光点挤向插头；越过卡位状态词换成「松手停用」，旁边列出会话，松手才生效，退回卡位内则取消
    不拖动时的确认点插头、详情里的开关、读屏操作同左有会话时，插头停在卡位，原处弹出确认：列出会话，「保留」或「停用」
    查看点名牌，底部卡片显示状态梯、会话和同族来源点名牌，下方检查器显示从属设置查看不改变任何状态
    处理点线上的结；结的 info 说明去电脑上处理点结，检查器只给一个下一步：安装、应用或重试App 不改安装、凭据和配置，与 ADR-0094 §01 一致
    键盘与读屏每个插头是一个开关，读出名称、状态词和会话数方向键在插头间移动，空格或回车切换结和名牌是普通按钮
    触觉只在三处：吸入孔口、越过卡位、电脑确认插到底与设计规范第 8 节「有分量的确认」一致；冲突退回不震动

    反馈与边界

    情况表现依据
    等待回执每根线各自停在孔口等待；后续操作排队，收到回执后按新修订号逐个提交ADR-0094 §04现行实现锁住整组，改为逐项等待需同步修订
    修订冲突插头退回电脑给出的位置，插头旁显示「电脑上刚有改动」§04 不静默覆盖
    其他设备修改插头自己移动，来源标签跟着插头停留 4 秒：「电脑上启用」「Pixel 9 上停用」快照需要可选的 origin 字段，按 ADR-0064 协商未协商时显示「其他设备已更改」
    电脑复核手机还不知道的新会话由电脑要求确认：插头退回卡位，原处列出会话§03 由 Host 在应用时复核
    回执丢失、重连先读快照，不重放；未确认的插头回到电脑结果，并标「未提交，已按电脑同步」§04
    电脑暂停灯从左到右依次熄成空心圈，线一根根垂下来。电脑上仍可插拔，新插上的线挂时钟结，状态为恢复后生效；手机显示已暂停，不能修改§03 运行时切换
    手机离线整块板冻结、去色，电流和光点停住，显示上次同步时间；插头锁住§04 不接受离线编辑
    接入失败插头保持插入，红色结；点结看原因，电脑端给出重试§04 启用与接入错误分开
    旧版电脑只显示电脑公告的 Agent，线直接接在插孔上，没有插头；顶栏 info 说明需要更新电脑端§04 兼容
    全部未启用插头都停在名牌旁；第一根线的插头朝插孔探两次作为提示；电脑概览的 Agent 卡直接给「启用 Agent」§03 无启用项时的入口
    减少动画去掉弹簧、电流、光点移动和探头提示，直接到终态；转圈停住设计规范第 9 节

    概览方案 A：来处标签

    状态常显

    每行直接显示灯和状态词，不再藏在悬停提示里；会话数和唯一的下一步跟在后面。强调色仍只给当前一步。

    变化有来处

    别的设备启停时，行从卡片里升起或按回，并带着「iPhone 上启用」「Pixel 9 上停用」停留 4 秒。底部常留最近一次变化，行消失以后也找得到原因。

    同步看得见

    标题右侧每台已配对手机一个胶囊：已同步是实心点，推送中转圈，离线时空心点加「待同步」，上线读完快照后点亮一次。

    情况概览显示规则与依据
    哪些行只列已启用的 Agent，按目录固定顺序；同族两行垫在同一块浅底上ADR-0094 §03 概览只列已启用来源；HOST-GUIDE-01 固定顺序
    每行内容标识、名称、灯与状态词、会话数、唯一操作：打开、安装、重试或配置。准备中和安装中，按钮保持宽度换成转圈HOST-GUIDE-01 单一操作；设计规范第 8 节加载态状态词与 Agent 页、手机端同一套
    其他设备启用先开槽，内容晚 120ms 淡入；来源标签停留 4 秒，状态随电脑的准备进度变化设计规范第 8 节：新出现的东西从材料里升起
    其他设备停用不立刻消失：灯熄、内容变淡，标「Pixel 9 上停用」4 秒，再按回材料、合槽设计规范第 9 节：动效回答刚才那个东西去哪了
    本机改动在电脑 Agent 页改完回到概览，直接是新结果，不补放动画；最近变化记为「电脑上…」只为没看见的变化做过渡
    多项同时到达按目录顺序依次进出，间隔 70ms；最近变化合并为「iPhone 上启用 3 个 Agent」3 秒内同一设备、同一方向算一批
    最近变化卡片底部一行：哪台设备做了什么、多久前；点开跳到 Agent 页并选中该项只留一条，不做历史列表
    设备同步每台已配对手机一个胶囊：已同步、正在同步、离线待同步、未连接Host 记录每台设备最后收到的修订号概览所需信息都在 Host 本地，不新增协议
    未启用数量底部右侧「6 个未启用」直达 Agent 页；全部启用时为「管理」；一个都没有时只给「启用 Agent」§03 无启用项时的入口；有启用项以后也找得到其余 Agent
    电脑暂停标题旁「已暂停」，灯熄成空心圈，电脑上新启用的行显示恢复后生效；手机胶囊都为未连接§03 运行时切换

    概览：另外四种呈现

    B 看过才褪

    在手机上启停时，人多半不在电脑前，4 秒的标签没人看见。B 把别处来的变化当作未读：概览在屏幕上满 4 秒，或指针扫过那一行，才算看过。

    别处启用
    行浮起一层，标识角上盖设备章，写「iPhone 上启用 · 12 分钟前」，看过后压平
    别处停用
    行不消失，压成一道印痕，看过才合上
    同步
    正常时不显示；手机离线又落后时，标题右侧出现「iPhone 待同步」
    代价
    Host 要记每条变化有没有在概览上被看过；锁屏、最小化不算

    C 送达回执

    同步挂在每次改动上，而不是挂在设备上。每张回执写明从哪台设备发出，另外每台设备收到没有。

    别处启停
    回执以来源开头：「iPhone 启用 → Pixel 9 ●」
    本机改动
    同样有回执，看得出手机有没有收到电脑上的修改
    收起
    全部送达 3 秒后收起；有设备离线就一直留着「待送达」
    代价
    行内多一列，名称列变窄；没有改动时看不出手机在不在线

    D 修订标尺

    把 Host 的修订号画成一把尺。最上一条是最近 8 次改动，每台手机一条轨道，填到它已收到的位置。

    别处启停
    新刻度从右端出现；手机上发起的改动有一根线落到那台手机的轨道上
    同步
    落后部分是虚线，写「差 2 项」；重新连上后填满
    查看
    指针移到刻度上，对应的行高亮，尺下写明这次改动；点刻度去 Agent 页
    代价
    信息最多，偏工程；卡片高出约 100 像素

    E 浮雕墙

    10 个 Agent 各占一块固定位置。启用的凸起，未启用的压平在卡片里，不显示状态，也不探测。

    别处启停
    那一块原地升起或压下，旁边不挪、不重排
    来处
    角上盖设备章，看过才褪，规则同 B
    入口
    压平的块点一下去 Agent 页启用
    代价
    未启用项也上概览，需修订 ADR-0094 §03「概览只列已启用来源」；卡片最高
    A 来处标签B 看过才褪C 送达回执D 修订标尺E 浮雕墙
    回答什么刚才谁改了什么我不在时改了什么这次改动别的设备收到没有每台手机落后多少全部 Agent 现在怎样
    人不在电脑前标签 4 秒后消失，只剩底部一条最近变化留到回来看过留到全部送达最近 8 次一直在尺上印章留到看过
    设备同步标题右侧每台手机一个胶囊只在离线待同步时出现挂在每次改动上每台手机一条轨道同 A
    布局变化行升起、按回同 A，停用的行看过才合上同 A同 A，上方多一把尺不重排
    Host 本地记录来源、各设备已收到的修订号再加是否看过同 A同 A同 B
    与 ADR 的差异无无无无需修订 §03

    与现状对比

    现在提案
    入口电脑：Agent 页下方的「启用 Agent」开关组；手机：设置里 10 个平铺开关一块接线台同时表达决定和事实；设置里一行入口，带 10 盏灯的灯排
    状态开关只表达启用，安装和接入在别处插头、线、灯、结各管一件事，一行看全
    提交中整组开关禁用，下方一个转圈每根线各自等待，可以连续操作
    停用确认手机每次都确认，不说影响线上有光点才有阻力和确认，并列出会话
    多端开关静默跳变插头自己移动并标出来源
    电脑概览状态只在悬停时出现；别的设备启停时，行静默出现或消失；有启用项后没有启用更多的入口状态常显；行升起或按回并标来源；底部留最近变化和未启用数量；标题右侧显示各手机是否已同步
    同族来源Codex、DeepSeek 的终端版与桌面版各占一行，看不出关系相邻两行垫在同一块浅一级的底上，终端与桌面角标，详情里互相跳转

    落地

    共用组件

    • 接线道：名牌、线槽与插孔、灯三段；手机横排，电脑竖排，几何共用
    • 插头开关：沿用 NeuToggle / SoftSwitch 的开关语义和读屏角色，增加孔口等待、已排队、卡位、锁定
    • 线：Compose Canvas、SwiftUI Canvas、QML Shape 各一份。盘绕 6 圈，松弛 0 到 9 pt；回位用 spring-drag，插到底用 spring-pop，松弛用 spring-page
    • 灯排：设置入口与电脑概览共用
    • 来源标签：复用 ADR-0083 F2 对象原位反馈

    数据与协议

    • 只读现有 agent.enablement.snapshot / result 与接入投影（就绪、运行数、错误）
    • 线的顺序取 Host 目录顺序；未知来源追加一行，用通用符号
    • 核心交互不新增帧；来源标签需要快照的可选 origin；逐项等待需要修订 ADR-0094 §04 的 App 行为
    • 概览：Host 本地记录每次写入来自哪台已配对设备、每台设备已收到的修订号，不新增协议
    • 不变：Host 唯一事实来源、修订号与冲突、停用由 Host 复核、旧端兼容、关闭项不探测
